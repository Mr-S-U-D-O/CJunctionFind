# CJunctionFind

CJunctionFind is an inventory management app for clothing stores. 

## Features
- Barcode scanning
- Photo uploading & compression
- Store location tracking
- Item categorization
- Supabase integration

## Setup
1. Copy `.env.example` to `.env` and fill in your Supabase credentials.
2. Run `npm install`
3. Run `npm run start` to start Expo server.
